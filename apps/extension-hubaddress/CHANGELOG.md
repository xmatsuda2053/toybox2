# Changelog (HubAddress)

本ファイルは HubAddress のリリース履歴を記録します。

## [v1.0.0] - 2026-11-27

### 初回正式リリース（v1.0.0）

職員情報・組織情報をサイドパネルで素早く検索・参照できる Chrome / Edge 向けブラウザ拡張機能 **HubAddress**（Manifest V3）の初回正式リリースです。

### 主な機能

- **高速な職員・組織ディレクトリ検索と仮想スクロール**: 大量データでも軽快に動作する検索フィルタ・仮想スクロール表示（ワイド画面では職員・組織の 2 ペイン同時表示に対応）
- **柔軟な並び替えとカード操作**: 職員一覧（所属部署・氏名／氏名／職員番号）および組織一覧（登録順／組織名／場所）のソート順切替、ハンバーガーメニューによる編集・削除、所属組織へのワンクリックジャンプ
- **充実したクリップボードコピー**: 項目単位のワンクリックコピーに加え、1 件分のカード情報コピーおよび検索・絞り込み中の全件 TSV コピーに対応
- **ローカルデータ管理（CSV / JSON）**: IndexedDB によるオフライン保存、職員 CSV・組織 CSV・一括 JSON のインポート（プレビュー確認付き）／エクスポート（BOM 付 UTF-8）および全件初期化
- **快適な操作性とカスタマイズ**: ショートカット（`Alt+Shift+H`）によるサイドパネル開閉、ライト／ダーク／システムテーマ切替、設定画面へのアプリバージョン表示
