# Changelog (Step-Note)

本ファイルは Step-Note のリリース履歴を記録します。

## [v1.1.0] - 2026-11-27

### 機能追加・操作性改善

- **日付選択コンポーネント（`datepicker-input`）に年月ジャンプ機能を追加** ([#591](https://github.com/xmatsuda2053/toybox2/issues/591))
  - カレンダーヘッダーの年月クリックによる「日 ⇄ 月 ⇄ 年」の 3 段階ドリルスルー切替に対応しました。
  - 年選択ビューに元号クイックジャンプ（令和・平成・昭和・大正・明治）と西暦年の直接入力欄（全角数字対応）を配置し、遠い過去・未来の日付を少ないステップで選択できるようになりました。

### 改善・リファクタリング

- **Markdown エディタ系 SCSS のトークン化・軽量化** ([#596](https://github.com/xmatsuda2053/toybox2/issues/596))
  - `markdown-editor` および `markdown-editor-preview` のテーマ配色を CSS カスタムプロパティへ一元集約し、不要な `!important` 宣言と重複スタイルを大幅に削減しました。

## [v1.0.1] - 2026-11-27

### 不具合修正

- **旧データ移行・バックアップ復元時の主キー `id` 型不整合を自動修復** ([#584](https://github.com/xmatsuda2053/toybox2/issues/584))
  - 旧 Step-Note（SnDB）移行データや過去バックアップの再インポート等により IndexedDB 上に文字列型の連番 `id`（`"1"` 等）が残存していた場合、DB スキーママイグレーション（`version(8)`）およびバックアップ復元完了後に数値型 `id` へ自動修復するよう対応しました。
  - 既存の数値 `id` と文字列 `id` が衝突している場合も、既存数値レコードを保護しつつ安全に退避・整理されます。

## [v1.0.0] - 2026-11-27

### 初回正式リリース（v1.0.0）

オフライン・単一 HTML で完結するタスク管理・作業記録アプリ **Step-Note** の初回正式リリースです。

### 主な機能

- **5 ペイン構成と一覧表示モードの切替**: Menu / Navigation / Task List / Task / Journal の標準 5 ペインに加え、タスク一覧テーブルでのフィルタ・ソート・セル直接更新に対応した「一覧モード」を搭載
- **タスク・課題・メモ・作業ログの一元管理**: Summary / Issues / Notes / Property / Logs タブによるタスク管理、関係者管理、年度管理、タグ・ラベル分類、クイックアクセス、および共通メモ（Scratch）機能
- **リッチな Markdown エディタ**: スプリット表示（編集位置・スクロール同期）、追従ヘッダー、ステータスバッジ、ID ジャンプ（`#<ID>`）、テンプレート挿入に対応
- **ローカル完結のデータ保全**: IndexedDB による自動保存、JSON バックアップ・復元、自動エクスポート設定、ストレージ使用量・進捗インジケーター
- **快適な操作性**: ライト／ダーク／システムテーマ切替、全体検索、閲覧履歴さかのぼり、キーボードショートカットヘルプ、フッターへのアプリバージョン表示
