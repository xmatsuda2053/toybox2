@shared/components 独立単体プレビュー環境

1. Default SearchInput

デフォルト状態。英文プレースホルダー（"Search..."）、虫眼鏡アイコン、with-clear 属性、250ms デバウンス。

2. Custom Placeholder

任意の placeholder（例: "Filter labels..."）を指定した状態。

3. Initial Value

初期値（value）が設定された状態。クリアボタンによる即時クリアとイベント発火を確認できます。

4. Loading State

非同期検索中の状態（loading 属性）。虫眼鏡アイコンがスピナーに切り替わります。

5. Fast Debounce (100ms)

debounceWait を 100ms に設定。高速に入力完了イベントを発行します。

6. Medium Size

サイズを medium に設定したバリエーション。

7. Default DatePickerInput

未選択状態（プレースホルダー表示）。クリックまたはフォーカスでカレンダーポップオーバーが展開されます。

8. Pre-filled DatePickerInput

初期日付（value="2026-04-15"）が設定された状態。「yyyy-MM-dd (EEE)」形式でフォーマット表示されます。

9. Size Variations (Small & Large)

size="s"（上）および size="l"（下）のサイズバリエーション。

10. Disabled DatePickerInput

disabled 属性が付与された非活性状態。ポップオーバーの展開および入力操作が抑止されます。

11. Markdown Editor & Preview (Standard GFM & Split View)

CodeMirror 6 と unified パイプラインを統合したエディタ＆プレビュー。左右スプリット表示、編集のみ、プレビューのみの表示切り替え、GFM（表、タスクリスト等）をテスト可能です。

12. Plugin DI Extension Demo (Open-Closed Principle)

コアコードを改修せず、外部から remark プラグインおよびサニタイズスキーマ拡張を注入（DI）した実証デモ。独自記法「:badge[ステータス]:」がリアルタイムにカスタムタグとしてレンダリングされます。
